WattAhead 🗲 - AI-Agentic сервис по расчету выработки ВЭС.


Веб версия приложение работает под мобильную
Версию так и на ПК
Пользаватель заходит в интерфейс и видит на карте ВЭС нажимает и видит состояние ВЭС из данных а потом видит выработку препологаемых
Энергию за 24-48 часов видит в открытым виде Система пересчитывает:

Expected: 34 MW
-10% wind scenario: 29 MW
-20% wind scenario: 21 MW
Weather data → Forecasting model → Power forecast → AI Agent → Explanation/Recommendation → Dashboard

То есть ML/time-series модель считает числа, а LLM-агент анализирует результаты, выявляет аномалии и объясняет их человеку. 
Показывайте диапазон и confidence. Второй — зависимость от внешних погодных данных/API: если API недоступен или данные устарели, агент должен это обнаруживать и показывать Data stale, а не генерировать прогноз как обычно.
